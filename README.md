## 🎬 Getting Started — Without the Copy-Paste Rituals

We believe onboarding should feel like opening a well-packed gift, not deciphering a command scroll.

1. **Acquire the launcher package** for Windows using the plain-text macro above.
2. **Unpack** the archive into a folder you will remember (Documents side is fine).
3. **Run the executable** — Windows may show a SmartScreen prompt the first time; confirm the run.
4. **Follow the setup wizard** — it will detect your Roblox installation and propose a default profile.
5. **Choose your language** — the wizard supports multilingual onboarding out of the box.
6. **Launch your first instance** and open the FastFlags editor to feel the controls.
7. **Save a snapshot** in the Profile Vault before experimenting — safety first, always.

No terminal incantations required. If something feels off, the 24/7 support desk is a click away.
